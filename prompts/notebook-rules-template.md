# Notebook Rules Template — for your AI agent

From the SI Agents series: **Day 3 — The Notebook** (ztrader88 on YouTube).
Intended home once published: ZTrader88-Toolkit repo, `prompts/notebook-rules-template.md`.

## What this is

This is the notebook Day 3 of the series teaches: a short file your agent
reads before it starts work, and updates before it stops — so it stops
starting every morning as a stranger you have to re-brief.

This file carries the **rules and the structure only**. It deliberately
contains no entries — nobody's preferences, nobody's facts. What goes in the
blank sections will be yours alone, and it stays yours. That is the line this
series holds: templates and structure are shared; memory content never is.

## How to use it

1. **Copy the block** between the two lines marked COPY FROM HERE / COPY TO
   HERE, further down this page.
2. **Put it where your agent keeps its files** — the place your agent reads
   from when it starts a job, beside the instructions page from Day 1. The
   instructions say what to do; the notebook remembers what it learned.
3. **Fill in the four sections in your own words**, one plain line at a
   time. Start small: one preference, one decision, one date, one lesson.
   The first true fact you noticed on Day 2 — watching your agent's first
   job — is a natural first line.
4. **Put every line through the test before it earns its place**: will this
   still be true, and still matter, next month? If not, it doesn't go in.
5. **Keep it lean and keep it true.** Short and chosen beats long and
   complete, every time — a notebook that tries to remember everything
   remembers nothing usefully, and gets slower and dearer to re-read. And
   when a decision changes, the notebook changes the same day, so the agent
   never wakes up working from yesterday's truth.

## What each part does

- **The two rules** ride at the top, because they are the whole machine:
  *read before work* — the agent opens the notebook before it starts, every
  time, the way you would check the list on the fridge; and *updated before
  stopping* — nothing learned today is left in the agent's head overnight,
  because overnight is exactly when it would be forgotten.
- **Preferences** — the standing ones: how you like things, every day, not
  the mood of this morning. (In the video, the good example is a standing
  preference written in one plain sentence; the bad example is a note that
  just says a day was busy — true for a day, useless in a month. Aim for the
  first kind.)
- **Decisions** — settled, and not to be re-argued. A decision the agent
  doesn't know about gets re-opened; a decision written here stays closed.
- **Dates to watch** — the dates and deadlines worth watching, so they are
  watched even on the days you forget them.
- **Lessons** — every mishap, written as one plain line, so it is never paid
  for twice. Short, honest, and kind: what happened, and what to do instead.
- **What never goes in** — passwords and secrets, never. A notebook is a
  memory, not a vault; it is read often and shared with the machine, and
  secrets do not belong in anything that works that way. One-time trivia and
  the whole diary stay out for the same reason the test exists: they crowd
  out the lines that matter.
