The Backup-Codes Check

If your phone died tonight — do you have backup codes, a second way in, and a copy somewhere safe? A two-minute self-test, done before a crisis. Free from ztrader88.

What this check is — and what it is not. It checks your own spare keys, set up by you, on your own accounts, while everything is working. There is nowhere on this page to type a code, a password, or anything else — and there never will be. Never type your backup codes into any website or tool, including this one. Codes are written down by hand, on paper, and kept somewhere safe. That is the whole point of doing it now, before the phone dies.

When you turn on two-step verification — the extra step after your password, usually a code sent to or made on your phone — most services offer you a small set of backup codes. Each code is a spare key: it signs you in once, on its own, when your usual way in is not there. Each one works once, then it is used up.

Google puts the reason in one line: create your backup codes in case you lose your phone. Google’s own page: Sign in with backup codes — Google Account Help.

Each service keeps them in the same place: its security settings, near the two-step verification setting itself. Sign in, open the security settings, and look for “backup codes” — you can usually see the set you were given, or make a fresh set.

One thing to know before you click: on most services, a new set replaces the old one — the old codes stop working the moment the new set is made. So make a new set only when you are ready to write the new codes down and put them somewhere safe, in the same sitting.

Paper in a drawer has one big strength: it cannot be hacked from the other side of the world. Nobody can phish it, sync it, or steal it with a password reset. What paper cannot survive is being lost, soaked, or thrown out by accident — so treat it like a spare house key: one copy, somewhere you would look for important papers, in a sealed envelope if you like.

The one place codes must never live alone is on the phone they protect — a photo of the codes in the phone’s own gallery is gone on exactly the night you need it. And never type them into a website or tool to “store” them — including this one. There is nowhere here to type them, on purpose.

Then use the service’s own recovery door — the official “I’m locked out” path each company runs — and expect it to be slower than a code would have been. There is no support number that can hand an account over, and recovery through the official door is free: anyone who offers to unlock your account for a fee is running a scam.
